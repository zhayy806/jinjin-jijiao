# 🍳 美食点单

帮中国年轻人看懂「斤两」的智能做饭助手。

菜谱写「猪肉 300 克」，年轻人根本不知道那到底是多少。美食点单把抽象的重量翻译成「一个拳头、一个鸡蛋」这种一眼就懂的说法，还顺带估算买菜钱。

## 已实现

- 斤两可视化换算（克 ↔ 斤 ↔ 两 + 「几个拳头」类比 + 估价）

## 规划中

- 按人数自动算份量
- 带真实价格的购物清单（爬虫抓取生鲜价格）
- AI 智能推荐（冰箱里有啥 → 今晚做啥）

## 本地运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload
```

打开 http://127.0.0.1:8000
